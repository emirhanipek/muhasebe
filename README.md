# Muhasebe Projesi

Bu proje, işletmeler için modern ve kullanıcı dostu bir muhasebe yönetim sistemidir.

## Özellikler

- Gelir ve gider takibi
- Fatura yönetimi
- Müşteri ve tedarikçi kayıtları
- Finansal raporlama
- Çok kullanıcılı sistem desteği

## Kurulum

1. Projeyi klonlayın:
```bash
git clone https://github.com/your-username/muhasebe.git
cd muhasebe
```

2. Bağımlılıkları yükleyin:
```bash
npm install
```

3. Veritabanı ayarlarını yapılandırın:
```bash
cp .env.example .env
# .env dosyasını düzenleyerek veritabanı bilgilerinizi girin
```

4. Uygulamayı başlatın:
```bash
npm run dev
```

## Kullanım

1. Tarayıcınızda `http://localhost:3000` adresine gidin
2. Yönetici hesabıyla giriş yapın
3. Dashboard üzerinden muhasebe işlemlerinizi yönetmeye başlayın
