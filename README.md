# muhasebe

## Proje Hakkında

Bu proje, muhasebe işlemlerini otomatikleştirmeyi amaçlayan bir uygulamadır. Temel özellikleri şunlardır:

- Gelir ve gider takibi
- Fatura oluşturma
- Raporlama ve analiz

## Özellikler

### Gelir ve Gider Takibi
- Gelir ve giderlerin kategorize edilmesi
- Otomatik hesaplama
- Detaylı finansal görünüm

### Fatura Oluşturma
- Profesyonel fatura şablonları
- Otomatik numara sistemi
- PDF export özelliği

### Raporlama ve Analiz
- Dönemsel raporlar
- Grafiksel analizler
- Excel export özelliği

## Kurulum

```bash
npm install
npm start
```
